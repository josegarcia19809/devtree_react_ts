# 🌳 DevTree
### 🔗 Clon de LinkTree con Express + React (Vite)

---

## 📖 Descripción

**DevTree** es un clon de LinkTree que permite a los usuarios crear una cuenta y compartir todos sus enlaces sociales en una sola página personalizada 🌐✨

Cada usuario puede gestionar y personalizar sus enlaces a redes sociales como:

- 📸 Instagram
- ▶️ YouTube
- 📘 Facebook
- 💻 GitHub
- 🐦 X
- ➕ Y muchas más

---

## ✨ Características

- 👤 Registro e inicio de sesión
- 🔐 Autenticación segura
- 🔗 Administración de enlaces sociales
- 🎨 Personalización del perfil
- 📤 Subida de imagen de perfil
- ⚡ Manejo de estado del servidor con React Query
- 📱 Diseño responsive

---

## 🛠 Stack Tecnológico

### 🔹 Backend

- ⚙️ Express
- 🟢 Node.js
- 🍃 MongoDB

### 🔹 Frontend

- ⚛️ React
- ⚡ Vite
- 🎨 Tailwind CSS
- 🟦 TypeScript
- 🔄 React Query

---

## 🎯 Objetivo

Construir una aplicación **Full Stack moderna**, aplicando:

- Arquitectura cliente-servidor 🏗
- API REST 🌐
- Persistencia de datos con MongoDB 📦
- Manejo avanzado de cache y estado 🔄
- Buenas prácticas con TypeScript 🧠
